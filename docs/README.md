# Akar documentation source

The public Markdown in this directory belongs to Akar and is imported into `vinicunca.dev/akar` from release tags. The shared documentation site generates the complete component reference from `pnpm docs:meta` output for the same tag.

The Dialog guide is adapted from Reka UI documentation at commit `78089a5fc90371196d533301a00c955be95c2b39` (MIT license, copyright UnoVue). It is reviewed against Akar's exported components; the upstream revision is a seed, not an ongoing documentation source.
